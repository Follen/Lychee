# 搜索数据源与类别语法

新增可选数据源按 PERFORMANCE.md 默认关闭。在 Lychee 设置的数据源列表中启用：

| 数据源 | 用法 |
| --- | --- |
| 背包物品 | 搜物品名称或 ID；显示总数量与背包格位，点击打开原生背包并搜索高亮。整理背包后会重新查找位置。 |
| 天赋方案 | 列出当前专精保存的方案，点击通过暴雪天赋界面应用；其他专精的方案在切换专精后出现。 |
| 装备方案 | 搜保存的装备方案名，点击装备，显示当前方案及缺失装备提示。 |
| 暴雪设置 | 搜具体设置文字，打开所属分类并滚动定位。`rl` / `reload` 重载界面；`cdm` 打开暴雪冷却管理器。 |
| 队伍钥匙 | `key` / `钥匙` 显示本人及当前五人队伍成员的钥匙。已解锁传送时可真实鼠标点击传送。右侧显示大秘境分数，悬浮显示当季逐本分数。 |

钥匙使用 LibKeystone 的 `LibKS` 协议，可与使用该协议的插件交换数据，不要求队友安装 Lychee。
只查询当前队伍，不请求公会全员数据。未收到钥匙显示“未知”；确认没有钥匙显示“暂无钥匙”。
重新查询或刷新时，超过 90 秒的缓存不再作为当前钥匙展示；查询按需请求，队伍成员移除时丢弃该成员缓存。
总分与逐本分数优先读取暴雪评分摘要；只收到协议总分而没有摘要时，逐本明细显示“未获取”。
传送是传送自己到该钥匙对应副本，不能传送队友。未解锁对应技能的条目没有传送动作。
传送映射覆盖已核对的 retail 12.1 当季八本，未来赛季需要更新映射。

## 类别冒号

`技能：冰霜` 只在技能中搜索；英文冒号也支持：`技能:冰霜`。
空后缀如 `背包：` 浏览该来源结果。未知前缀保留为普通搜索文字，不静默变成全库筛选。

支持技能/玩家技能、坐骑、背包/背包物品/物品、天赋/天赋方案、装备/装备方案、
设置/暴雪设置、钥匙/队伍钥匙、首领、菜单/游戏菜单、纹章、宝库/宏伟宝库。
常用英文前缀包括 spells、mounts、bags、talents、gear、settings、key、keys、bosses。
筛选不会自动启用已关闭的数据源。

## 性能和使用边界

首次启用分批建立目录，目录变更只提交差异。隐藏搜索不关闭已启用数据源的事件驱动目录维护；
禁用数据源停止事件与后台任务，Host 保留有限的记录以支持既有恢复契约。战斗中暂停重建，
搜索和动作仍遵循 Lychee 既有战斗锁定规则。没有新增每帧轮询。

本次包含新增加载模块，更新后需要重启客户端。
