# 搜索数据源与类别语法

自带数据源随 `addon/Lychee` 单包交付，默认参与搜索，并服从角色设置中的显式关闭。这里的开关只控制搜索参与，不停止来源的后台功能；其他新增可选功能遵循 [PERFORMANCE.md](../PERFORMANCE.md)。

| 数据源 | 用法 |
| --- | --- |
| 背包物品 | 搜物品名称或 ID；显示总数量与背包格位，左键通过安全动作使用物品，右键可定位背包并高亮。整理背包后会重新查找位置。 |
| 天赋方案 | 列出当前专精保存的方案，点击通过暴雪天赋界面应用；其他专精的方案在切换专精后出现。 |
| 装备方案 | 搜保存的装备方案名，点击装备，显示当前方案及缺失装备提示。 |
| 暴雪设置 | 搜具体设置文字；左键执行该设置的默认动作，右键提供定位、直接调整、开关或恢复默认等适用分支。`rl` / `reload` 重载界面；`cdm` 打开暴雪冷却管理器。 |
| 队伍钥匙 | `key` / `钥匙` 显示本人及当前五人队伍成员的钥匙。已解锁传送时可真实鼠标点击传送。右侧显示大秘境分数，悬浮显示当季逐本分数。 |

钥匙使用 LibKeystone 的 `LibKS` 协议，可与使用该协议的插件交换数据，不要求队友安装 Lychee。
只查询当前队伍，不请求公会全员数据。未收到钥匙显示“未知”；确认没有钥匙显示“暂无钥匙”。
重新查询或刷新时，超过 90 秒的缓存不再作为当前钥匙展示；查询按需请求，队伍成员移除时丢弃该成员缓存。
总分与逐本分数优先读取暴雪评分摘要；只收到协议总分而没有摘要时，逐本明细显示“未获取”。
传送是传送自己到该钥匙对应副本，不能传送队友。未解锁对应技能的条目没有传送动作。
传送映射覆盖已核对的 retail 12.1 当季八本，未来赛季需要更新映射。

## 设置参数与自然语言

`把音量设置到30`、`音量30`、`set volume to 30` 可生成主音量参数调用；音乐、音效、环境和对话音量属于各自设置目标的动作分支。布尔、数值、选项、多选及颜色操作只在当前设置提供相应能力时可用；需要原生应用步骤的设置不能伪装成立即生效。没有已确认可写路径时保留定位动作。

普通设置结果与参数调用由同一个 `builtin.blizzard-settings` Provider 提供。通用语法词在 `Builtin/BlizzardSettings/Language.lua`，设置别名在 `Aliases.lua`；音量的专用词表与范围判断在 `Builtin/Audio/`。这些是 Provider 业务规则，不是 Host 的全局分词表。

## 类别冒号

`技能：冰霜` 只在技能中搜索；英文冒号也支持：`技能:冰霜`。
空后缀如 `背包：` 浏览该来源结果。未知前缀保留为普通搜索文字，不静默变成全库筛选。

支持技能/玩家技能、坐骑、背包/背包物品/物品、天赋/天赋方案、装备/装备方案、
设置/暴雪设置、钥匙/队伍钥匙、首领/团本首领、菜单/游戏菜单、纹章、宝库/宏伟宝库。
常用英文前缀包括 spells、mounts、bags、talents、gear、settings、key、keys、bosses。
筛选不会自动启用已关闭的数据源。

## 性能和使用边界

目录首次需要时按所属 Provider 规则准备，目录变更只提交差异。关闭参与搜索或隐藏面板取消相关查询，不关闭来源的独立后台功能；所有者停用才按自身生命周期停止事件与任务。目录的保留与恢复规则由各功能实现，不能把清理临时索引说成卸载插件。战斗中暂停不适用的重建工作，搜索和动作继续遵循战斗锁定规则。

已有当前结果渐进显示，不等待所有慢来源完成。加载中、恢复中和暂时不可用要区分；未恢复的固定项或最近记录不能执行。

本次包含新增加载模块，更新后需要重启客户端。

钥匙角色名按职业着色，结果使用副本图标；总分与逐本分数按游戏评分档位着色。悬浮框分列显示成绩与分数：自己的成绩优先取赛季限时记录，队友依已获取摘要标注限时／超时，不将超时层数当作限时层数。

## 正式服怪物与团本

- 荔枝大米助手：内部 ID `builtin.ldt`、搜索前缀 `ldt:` 保持不变，中文入口和结果类别显示“荔枝大米助手”，英文显示 LDT。怪物/技能搜索及模型详情保持原流程。
- 团本首领：内部 ID `builtin.bosses` 保持不变，仅保留原生指南团本页列出的首领；支持首领名、技能名和 ID，普通/英雄/史诗按实际关系筛选。难度词置于开头并以空格分隔；完整技能原名优先，避免把名为 Heroic Resolve 的技能误当作英雄难度请求。
- 同一首领/技能跨难度合并，点击跳到选定难度和 section，附加动作列出可用难度。不同首领或不同技能 ID 不因同名而合并。
- 关系采集与验证见 [首领关系数据与验证](guides/PROJECT_STRUCTURE.md)，名称规则见 [i18n.md](../i18n.md)。怀旧服支持范围本轮不变。
