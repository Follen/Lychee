# Provider 统一运行时与 SDK 托管能力

用户授权：清理旧命令/能力/意图通路，公共生命周期能力纳入 SDK，统一测试装配。普通具名记录、匹配评分、角色默认开启、用户选择与安全动作保持。

## 职责

- ProviderRuntime 是公共接收与业务身份所有者；Registry 保留搜索来源和视图的事务发布，不再维护旧命令协议。
- Resources 是托管活动的所有者。Provider、query、view 分别拥有作用域；先失效再取消，停止原因传给清理函数。公开句柄不暴露私有状态。
- ProviderData 提供按角色命名空间设置与作用域内有界缓存；缓存不进入 SavedVariables，设置不随关闭清空。
- SDK revision 7 添加能力，旧 revision 1–6 的 Provider 接入继续工作。旧私有 Command/Capability/Intent 不再是测试或运行契约。
- 测试装配集中公共依赖，游戏替身和独立匹配参照仍属于各测试；实际 TOC 另做装配验证。

## 成本与门禁（实施前）

触发：显式 SDK 调用；无托管活动时不创建事件 frame/timer，不新增常驻 OnUpdate。作用域按需创建，任务完成/关闭/禁用/注销释放。单 Provider 同时托管最多 64 个资源；分批任务继续使用一次性 timer，不抢占同步 Lua。事件 frame 共享且无订阅后取消事件与脚本。

设置按 Provider/角色隔离；每个值限定普通数据、大小和深度。缓存按显式容量/字节预算淘汰，不以每次输入完整 GC 控制内存。不修改已有搜索内存、分配或帧时间门槛；完整旧性能门禁继续运行，新增资源测试单独测重复操作保留增长和活动对象归零。

验收：旧回复、同 ID 重注册、取消重入、重复清理、失败回滚、页面构造失败、战斗中断、设置隔离、缓存边界、独立查询与动作等价；正式文件清单、Lua/XML/TOC/wowdoc、完整契约。离线不证明游戏战斗/taint/视觉，客户端另测。资料使用 wow-ui-source / retail / latest，resolvedCommit 8ea15b61e45c0ed4eba01439c90757f86eb78d34；精确 API 查询记录随验证保存。
