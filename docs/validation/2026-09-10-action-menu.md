# Action menu styling

The native context menu used its default textured translucent background, compact text and gold additive highlight. Lychee now assigns its own menu mixin to its row owner, while retaining native placement, dismissal, frame pooling and action dispatch. Components owns the opaque background, thin border, symmetric 5-unit container inset, 32-unit rows, 12-unit body text and 12-unit horizontal text inset. Measured item width is bounded to 176–360 units; long labels remain single-line. Hover uses the existing muted red selection color.

Versioned wowdoc evidence is stored in `docs/architecture/2026-09-10-action-menu-wowdoc.json`: sourceId `wow-ui-source`, product `retail`, requestedRef `latest`, resolvedCommit `8ea15b61e45c0ed4eba01439c90757f86eb78d34`. Source check reported identical local/remote commits. `MenuUtil.lua:151` creates an owner-specific menu; the preceding `SecureGetMenuMixin` reads `ownerRegion.menuMixin`. `MenuTemplates.lua` supplies the Generate/GetInset/GetChildExtentPadding style contract. The same version's implementation guide documents AddInitializer, button.fontString and returning width/height from an initializer. MenuVariants.CreateHighlight supplies button.highlight and native hover visibility.

The new style uses native AttachTexture pooling. No global menu functions, shared font objects or other owners are modified. Native pooled regions receive initial setters without persistent theme-cache stamps, because menu reinitialization resets them. There are no new events, timers or OnUpdate callbacks; work runs only while opening a menu. The headless executor remains usable without UI components.
