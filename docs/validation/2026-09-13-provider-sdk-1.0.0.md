# SDK 1.0.0 与五包拆分验证

2026-09-13，分支 `codex/provider-sdk-1.0.0`。本记录随实现一起提交；具体交付 hash 和游戏同步结果以该次提交及最终交付记录为准。

## 完成范围

- Host 与 Player、Encounters、Integrations、Inspector 分离，真实 TOC 使用各自私有命名空间。Host 不再持有业务 Modules、完整目录、业务 DB 或识别页工厂。
- API 3 / revision 1 只接受统一候选 query；SDK 发行版本 1.0.0，旧接口拒绝。Catalog/Score/Resources/Storage 是独立能力，项目启动模板不作为公开 SDK。
- Player 自有角色 SV，普通设置使用嵌入 Storage，成就使用自身专用 schema；未知/损坏/未来版源保留。其余包无持久需求时不创建空 DB。
- 管理页按注册来源分组，关闭保留、注销移除，用户偏好和实时可用性分开；长类别单行且限宽。识别页语言资源归识别包。
- 构建合同明确五包与 SDK 全部文件，拒绝混入文档、越界路径、遗漏资源、重复加载及 SDK 副本漂移。SDK Storage 按原字节复制。

## 离线性能读数

Lua 5.1 离线夹具，GC 和墙钟测量与真实游戏分开。容量/CPU 上限保留原值；下列不是游戏内常驻内存承诺。

| 场景 | 本轮读数 / 结论 |
|---|---|
| 五包 TOC 冷加载，不含 LDT | 约 1473 KiB；小于原 1474 KiB 基线上限。 |
| 五包 TOC 冷加载，包含 LDT | 约 1849 KiB；小于原 1858 KiB 上限。 |
| 扩展来源 100 查询 | 3713.5 KiB 累计分配，回收后增长约 0，45 ms 累计；原 4096 KiB 门禁通过。 |
| 团本技能 20 查询 | 约 6.3 MiB 累计分配，中文增长 0.2 KiB、英文增长 32.2 KiB，单批约 2 ms；原门禁通过。 |
| 成就 6002 条 | 821.5 KiB 保留；10 次温恢复分配 1386.5 KiB、无保留增长、零成就枚举。 |
| 页面反复开关 100 次 | 最大 4 ms，零新增 Frame、回收后无持续增长。累计临时分配另记，不能称零分配。 |
| 资源 1000 次启停 | 约 6 KiB 保留增长，零新增 Frame、关闭后零登记资源。 |
| 翻译器 20000 次热读取 | 零再次编译、零保留增长；不同来源同名键和外部输入修改隔离。 |

测试过程中曾抓到旧测试依赖、无效空索引对比、字节换行漂移及一次页面计时超限；已修正有效断言、交付生成与无用分支，最终完整入口通过，未提高原 CPU/内存阈值。TOC 事件数由 3 增至 4，仅增加一项按需撤销的 SavedVariables 就绪监听，详见 PERFORMANCE.md。

## 实机限制与交付

尚未在本轮五包结构下重启 WoW 验证实际 UI、模型、动作及长期常驻。新增四个 AddOn 必须完全退出并重启客户端，启用五包；只 /reload 不足以发现新插件。旧录像与旧性能 Ticket 不作为当前实现通过证据。

提交后仅同步五个清单内运行时包到正式服 AddOns 父目录，逐文件比对 SHA-256；保留并列出目标额外旧文件，不擅自删除。SDK、文档、分析、测试和工具状态不进入游戏。
