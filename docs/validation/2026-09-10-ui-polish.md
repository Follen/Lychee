## Thumb length follow-up

Live screenshot showed the proportional thumb nearly filling the track for slight overflow. Cap thumb height at 48 UI units, retaining the 24-unit minimum and track-height bound. Position and drag mapping continue to use the remaining track travel, so the complete range stays reachable. Regression covers 210 total / 200 visible units: 48-unit thumb and 152-unit bottom offset on a 200-unit track.
