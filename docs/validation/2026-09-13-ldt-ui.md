只修改 LDT View、对应文案与测试，搜索算法、目录数据、排名、结果与 Provider/SDK 协议不变。用户取消了额外 ExwindTools 技能机制标签，本次不读取 EXSP 或添加卡视野、昏迷等扩展技能数据；原有怪物基础特性仍保留。
