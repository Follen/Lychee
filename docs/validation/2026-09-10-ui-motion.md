# UI 动效实施预算

范围：整体动效体验优化，不将原先即时刷新定性为闪烁故障。搜索结果与动作逻辑保持原有代次失效规则。

动效意图：窗口伸缩提供空间连续性，页面与结果的轻透明度过渡提示内容更新，选中底和竖条提供快速反馈。无需逐行延迟、弹跳、模糊或位移受保护点击目标。

实现前预算：原生 Alpha 160 ms 开场、140 ms 页面切换、100 ms 选中与提示；尺寸约 220 ms。每个目标只有一个有效 Alpha，最多 96 个有限 UI 目标；一个活动尺寸任务和一个按需创建的尺寸驱动，结束后移除 OnUpdate、隐藏驱动。关闭与战斗取消活动，迟到完成不得重开窗口。重复输入从当前尺寸接续，不排历史动画。

冷态模块加载零 Frame/原生动画/订阅；首次动效才创建目标 AnimationGroup。控件池复用；1000 次重定向不增加对象；2000 次固定操作分配预算 <512 KiB，结束无活动任务，最多 96 个已创建原生组。动态尺寸每帧仅更新一个高度，不重新创建/重绑列表；实际客户端帧耗时待验证，离线单批目标 <1 ms（批次测量）。减少动态效果开关保留即时反馈并取消过渡。

## 最终验证

组件位于 package/Lychee/UI/Motion.lua，通过 TOC 在 Theme 后加载。原生 Alpha 用 GetSmoothProgress 接续当前画面，尺寸使用 cubic ease-out。单一尺寸任务记录复用，任务结束清除 region 引用。实际调用覆盖开合、尺寸、设置／功能页切换、标题更新、选中底和红条、按下文字反馈、提示框；滚动／拖拽保持直接反馈，不叠加惯性。设置页提供标准／减少动态效果。用户明确要求启用此动效体验，因此标准模式默认生效。

完整契约检查通过；原生边界模拟覆盖反向、同状态不重播、取消回调、尺寸目标变化、战斗禁止 setter、减少模式、96 组容量、关闭后零回调，以及真实 Palette 的动画关闭／快速重开。2000 次 Alpha 变化和 2000 个尺寸周期均测得 0.00 KiB 额外任务分配，CPU 为 1–2 ms 总量（粗粒度单机离线样本）。加载模块零引擎对象，首次尺寸创建 1 个驱动；专项测量共 1 个 Alpha 组，另单独填满容量验证上限。现有 UI/搜索性能门禁未放宽。

Lua/XML/TOC 静态检查、wowdoc validate（45 Lua，无诊断）和差异检查通过。API 证据来自 wow-ui-source/retail/latest，resolvedCommit=8ea15b61e45c0ed4eba01439c90757f86eb78d34，见 motion-api、motion-native-api 与 motion-clipping-api JSON。游戏内 60/120 FPS、不同 UI 缩放、战斗、真实受保护按钮与原生动画观感仍待验证；不得把模拟结果称为实机流畅性保证。本次新增 TOC 模块，同步后重启客户端。
