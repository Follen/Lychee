# 搜索结果复用最近使用比例

按用户最终选择，以最近使用为基准，而非放大最近使用。搜索结果从 58 高/32 图标/14 号标题调整为 46 高/28 图标/12 号标题，统一 592 行宽、6 行距、12 列表左边距、8 图标内边距、48 标题内边距和 2×22 竖红条。公共尺寸放入 Theme.Metrics；搜索结果有副标题时显示两行，无副标题时标题垂直居中。

最近使用保持既有无底色选中样式；搜索结果移除整行选中高亮，底色始终与面板一致。选择、悬停与键盘移动仍更新竖红条，安全动作、提示框、滚动、固定与拖拽语义保留。DESIGN.md 同步修正旧的横排最近使用和不一致尺寸描述。

仅有限尺寸常量与布局分支变化，不增加 Frame、Texture、事件、计时器或目录缓存。标题仅在单双行状态改变时重设锚点。旧完整测试在改变行高后触发固定高度断言，更新到用户要求的新比例，并增加真实 Palette 中最近使用/搜索行的宽高、图标与红条比较，以及选中态没有背景高亮的断言。
