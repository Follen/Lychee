# LDT 展开、布局与说明阅读修正

前版提交 `b9ba367`。用户实机截图证据：同步毒液处于第六行，展开后的两项被旧“每六行分页”挤到下页；技能名称继承通用导航按钮居中，图标和名称脱节；需要数字高亮和“毒牙尾王”搜索。用户确认特殊模型取景无需修改。

## 最终实现

- 每页六个技能组，子行属于组、不会影响总页数。最多八行复用，第六组展开两项立即可见；展开更多内容时滚动当前组页。单页隐藏分页箭头与页码。
- 统一正文12号、名称在图标后6像素左对齐。保留模型尺寸、取景、拖动和缩放。下方分隔线、技能说明和手势提示随列表高度定位。
- 内容高364–416，Host总高452–504，仍低于518上限。Host仅接受当前挂载实例的高度请求，Mount先保存、导航成功后提交；返回搜索、换页或失败后旧实例不可修改新页面。沿用已有高度动画，不新增驱动。
- 描述中的范围、伤害、时间、间隔、百分比数字使用主题浅荔枝红；原文、已有颜色、超链接、纹理/atlas转义原样保留。技能列表滚动不会重置说明滚动，只在选中ID或原文变化时格式化、回到顶部；关闭清原文引用。
- “毒牙尾王”“毒牙尾王boss”“毒牙最终boss”、副本全名尾王和英文 final/last boss 在现有查询作用域按实际最高 bossOrder 找末位首领。不硬编码NPC、不建立新索引、不读取无关技能。未知副本尾王返回空。
- 其余搜索结果、同名分组和Shift链接语义不变；不读取额外Exwind机制数据。

## 性能边界

八行替代六行是为页尾展开即时可见增加的两个固定复用行；另一个公共滚动条只在溢出时显示，关闭停止拖动。组数据仍至多64技能/128展开项，不按技能总数创建框体；没有空闲轮询或全量名称缓存。保留原加载、查询分配和CPU硬门禁。详情高度由Host统一管理，未改动开关动画或Logo。
