# 公共浮层、分隔线与缩放验收

日期：2026-09-13。基线提交：`7969c6c`。需求来自用户提供的右键菜单、技能 tooltip 和小怪详情实机截图。设计、生命周期、对象代价与修改前 WoW API 证据见[设计记录](../architecture/2026-09-13-ui-surfaces.md)，现行规则已更新至 [DESIGN.md](../../DESIGN.md)。

## 交付行为

- 右键菜单原本已有 Components 专用样式，本次将矩形描边背景改为复用 Theme 圆角表面，采用 8 内边距、30 行高和暖白正文；保留原生菜单定位、关闭、池化及前景红色悬停。
- 原来小怪页直接绘制 GameTooltip。本次将 ResultList 提示框渲染收拢到 Components，搜索、首页、技能、怪物特性和模型操作共用一个延迟创建实例。调用方提供标题、元信息、说明、操作提示及表格标题，通用组件不依赖 Host 的本地化对象。带 owner 的关闭不会隐藏其他入口的提示；重复关闭不再重复取消已经结束的动画。
- 删除主面板底栏和标志旁、小怪详情标题/两列/阅读区、插件识别详情的装饰分隔线。内容布局与原始功能不变，选择标记、展开箭头、输入边界、滚动条及识别目标轮廓保留。
- Theme 的整体缩放基准为 1.15；主窗口保留屏幕边缘适配，菜单与 tooltip 读取它实际应用的缩放。插件识别独立浮层按相同基准及自身大小适配视口。未添加设置或修改存档。
