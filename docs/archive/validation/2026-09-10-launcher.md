# 黑红快速入口验证

用户批准深色 uTools 效果图的布局，并要求使用已有荔枝 Logo、面板更黑、红色作为强调色。实现保留紧凑搜索框、最近使用和单列结果；不采用效果图中的示意技能图标。

## 行为与查档

- 640 UI 单位宽，10 单位圆角；搜索框不再显示红色矩形边框。面板底色为 RGB 14/14/16，选中行使用暗红底。
- 首页最多五个最近入口，按内容收缩；每次重新打开清空旧搜索词。结果显示八行，超过一屏通过滚轮或方向键复用行对象。
- 技能物理点击由 SecureActionButtonTemplate 执行，显式设置 `useOnKeyDown=false` 与 `LeftButtonUp` 对齐。Enter 不模拟安全点击；技能失败保留重试入口，成功收起并记录最近使用。
- 窗口使用 SecureHandlerStateTemplate。`[combat] hide; idle` 驱动触发 `_onstate-combat`，安全片段只在 hide 状态关闭窗口，idle 不显示。普通 Lua 在战斗中停止搜索、清焦点并延期清理，脱战后清理，不重开。
- 准备按钮可发生在祖先隐藏时；真实 PreClick 仍检查可见性、会话/查询代次、来源修订、扩展启用状态和动作可用性。

查档源：`wow-ui-source`，product `retail`，requestedRef `latest`，resolvedCommit `8ea15b61e45c0ed4eba01439c90757f86eb78d34`（本地目录含 12.1.0 标签；latest 查询 matchedTag 为空）。完整 path、line、excerpt 保存在同目录 `2026-09-10-launcher-wowdoc.json`。

- `Interface/AddOns/Blizzard_FrameXML/SecureTemplates.lua:795`：`useOnKeyDown` 属性未设置时才读取 `ActionButtonUseKeyDown`；805 行的点击分支区分 down/up。

## 资源与性能边界

原始 `lychee-logo.png` 和 `lychee-logo.tga` 与修改前 HEAD 逐字节相同。新增 rounded-corner.tga 为参数化几何纹理：32×32 BGRA，8 位 alpha，顶端原点；白色左上四分之一圆，抗锯齿来自每像素 8×8 子采样。四角 UV 复用翻转，边缘透明通道已独立核验。

首页预创建按钮从 64 减为 8；结果从 12 个卡片变为 8 个可见行，首次施法结果按需创建安全按钮，之后复用。新增回归断言滚动时 frame 创建数不增加，已有测试确认相同数据不重复调用视觉 setter。移除了打开/关闭的 Lua 动画驱动，没有新增插件 OnUpdate 或轮询；战斗显隐委托暴雪共享安全状态驱动。最近记录只在打开首页或可见首页的数据变更时解析，普通搜索按键不重建首页索引。

这些是代码和离线计数证据，不是游戏 CPU 或帧时间测量。登录、空闲、单目标战斗、多目标/团本、姓名板峰值及界面开关场景的实际 CPU、Lua 内存、帧时间和 taint 仍需客户端验证；本轮没有可用的实机截图或采样。

## 游戏验收与回滚

提交后将 package/Lychee 覆盖复制到 `D:\Game\World of Warcraft\_retail_\Interface\AddOns\Lychee`，比较运行时文件清单和全部 SHA256，不删除目标额外文件。同步完成后使用 `/reload`；若客户端未识别新增圆角资源，重启客户端再检查。

验收：首页尺寸、圆角接缝、原始 Logo、中文长标题、鼠标点击和拖动、按下按键施法开关两种设置、打开时进入战斗、脱战不重开、隐藏后无焦点残留。发生回归时使用 `git revert <本次提交>`，验证后按相同流程复制回正式服，不改写提交历史。
