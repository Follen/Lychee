## 实施前的成本与契约

- TOC仍加载代码，不宣传全量Lua按需加载。不拆成额外AddOn，不引入第一次搜索才支付的解包。
  首领目录在同一加载阶段使用紧凑表示，Provider初始化和全部数据语义保持。
  基线76文件：23ms执行、3161.7KiB累计分配、1313.5KiB回收后保留、2基础Frame/3事件；
  JournalCatalog单文件分配434.3KiB。预算同场景回收后减少至少32KiB，不新增Frame或驱动，
  加载执行不超过基线两倍（离线文件IO/编译混合口径，非游戏帧率）。
- ViewHost保留create/Mount/Update/Unmount/Dispose正常顺序和返回值解释。
  Provider保有最多一个示例面板，无宿主全局缓存、无协议revision变化。
  同步生命周期串行化：重入Mount/Update返回PANEL_BUSY；回调内Unmount标记取消，
  回调返回后清理，不排timer。异常/取消清理仍按Unmount→Dispose；实例归属独立于可修改context。
  预算1000次暖开关不新建UI，关闭无活动/业务引用；累计分配低于旧实现，禁止未启用时创建面板。
- Elles保持原生加载与导航时机、页面/设置ID、分数/排序/内容、快捷入口、上限和取消行为。
  兼容依赖集中，不缓存跨查询或跨yield的可变上游目录。只复用已有读取证据和有界评分scratch；
  延迟/禁用不积累任务。用同输入结果与动作对照验证，不能通过丢设置或覆盖范围缩水提速。
  20次1000页查询累计分配基线约1668.7KiB；目标降低不增加保留增长，现有1ms/32项批界限保留。
- 文档明确TOC执行、Provider初始化、索引构建与UI创建的差异。
  显式说明实例缓存、父级切换、异常清理、业务引用和永久hook的责任。

## 完成内容与兼容边界

1. 首领目录改成连续三元组，不改变加载阶段，不引入运行时解包。独立快照校验覆盖全部 1154 个首领、214 个实例的顺序、ID、归属、名称和图标；中文、英文路径均更新并测试。生成器增加 `--check`，防止数据与生成结果漂移。
2. ViewHost 减少每次回调的临时参数表；串行处理同步生命周期，保证重入、异常和取消时不把已经关闭的缓存实例重新显示。所属扩展在工厂执行期间被停用也会取消创建；归属不受第三方修改 context 影响。正常调用顺序及回调返回 false 的原有解释保持，重入失败明确返回 PANEL_BUSY，取消返回 PANEL_CANCELLED。
3. Elles 内部依赖集中到 Adapter，能力检查与失败处理有明确边界。查询先判断候选能否进入有界结果，再构造完整记录，复用淘汰行。保留评分、排序、结果上限、分批取消及导航参数，不增加全局索引或跨 yield 的可变页面缓存。上游内部结构变化仍需维护适配器。
4. 补齐生命周期和适配兼容性文档、接口注释与复用示例。示例只缓存一个面板，关闭清除业务引用；父级切换或布局中途失败后能重试，复用已有控件。宿主不承诺自动永久缓存，也不引入没有实际需求的新注册协议。
5. 架构、协议、目录说明区分 TOC 执行、Provider 激活、索引构建和 UI 创建。没有把“按需创建窗口”描述成“所有 Lua 按需加载”。原有已满足预算的无关模块保持不变。
