# 正式服玩具 Provider（0.2.8）

基线 dabfeaa。新增 builtin.toys，仅 Mainline 与正式服 fallback TOC 加载，默认参与搜索，遵守角色显式关闭。复用 toys.tga 和已存在的结果行，不新增图形资源。

## 用户流程与断言

| 流程 | 断言 | 当前证据 |
|---|---|---|
| 搜索玩具名称、物品 ID、toys: / 玩具: | 仅已收藏玩具，完整目录不受玩具箱过滤影响 | 离线通过 |
| 普通玩具左键 | secure-item 根据 PlayerHasToy 选择 type=toy、toy=itemID，无背包数量要求 | 安全按钮替身通过；真实硬件点击待验收 |
| 放置类玩具 | 立即关闭搜索，原生目标光圈保留，玩家点击地面放置 | 宿主窗口和按钮替身通过；实际放置待验收 |
| 右键或 Esc 取消放置 | 使用游戏原生取消行为，不脚本代选或取消 | 真实客户端待验收 |
| 冷却／地点限制、战斗拒绝、取消后重试 | 游戏应用实时限制；战斗中不准备受保护动作 | 战斗替身通过；冷却／地点和实际重试待验收 |
| 按下后换绑、收藏失效、按钮复用 | 不执行过期目标，toy/item/spell 属性正确清理 | 离线通过 |
| 数据加载、获得玩具、停用恢复 | 同步/异步加载恢复，新获得玩具补充，停用零任务和订阅 | 离线通过 |
| 中英文及语言家族 | zhCN/enUS/zhTW/enGB 查询与词典正确 | 离线通过；实际界面待验收 |

## 数据与接口证据

wowdata 固定 remote/cn/wow/12.1.0.69875/zhCN，Toy.db2 1163 行、1163 个物品 ID；可维护输入为 assets/toys/catalog.json，tools/build_toy_catalog.py 生成 Data.lua。目录不保存名字、描述、收藏或冷却。未来客户端版本应更新 ID 快照；本会话 NEW_TOY_ADDED 可补充热修新增 ID，总数不超过 4096。它不能承诺提前覆盖未来版本所有新增玩具。

wowdoc source list/check 已执行，retail requestedRef=12.1.0，resolvedCommit=4e3cbb8c5609e4bfc332c0aebbfa4d79731fab59。完整 path/line/excerpt 见 [接口证据](2026-09-20-toys-evidence.json)。

- Blizzard_FrameXML/SecureTemplates.lua:404 原生 SECURE_ACTIONS.toy 读取 toy 属性，执行 UseToy / UseToyByName。
- Blizzard_Collections/Mainline/Blizzard_ToyBox.lua:303、322、354 分别使用过滤后的索引、玩具信息和 PlayerHasToy。实现避免读写该过滤列表。
- Blizzard_APIDocumentationGenerated/ItemDocumentation.lua:589、824 为 GetItemIconByID / GetItemNameByID；ITEM_DATA_LOAD_RESULT:1817 提供 itemID、success。缺失名称按本地化 ID 占位并有界请求数据，不永久负缓存。
- C_ToyBox.GetToyInfo 在原生源码有调用，但当前 wowdoc API 索引缺失而产生 api_not_found；最终实现直接使用已记录的 C_Item 名称/图标接口，四客户端 validate 均 valid=true。未隐藏或绕过诊断。

SDK/API 仍为 1.0.0；secure-item 既有物品 ID 契约扩展使用已收藏玩具，协议中英文同步说明。安全按钮不生成宏、不脚本调用受保护使用，不调用 ClearCursor 或 SpellStopTargeting。点击记入最近使用沿用物品动作规则，表示使用尝试，不作为施法成功证明。

## 成本与检查

遵循 PERFORMANCE 第19节：一个目录 Frame，TOYS_UPDATED / NEW_TOY_ADDED / ITEM_DATA_LOAD_RESULT 三个业务事件及既有战斗生命周期；32项或1ms检查点、16条提交批次；最多4096个ID及对应pending。温搜索不读收藏，空闲无活动timer/OnUpdate。数据所有者为玩具模块，无SV；目录只保留Host已验证记录与标量签名，不再复制一份完整业务记录。

固定1163 ID、隔项收藏（581条）模型，从无该Provider目录到建成目录：中文保留1422.0 KiB，英文1601.8 KiB；20次查询分配214.3 KiB，回收后增长2.1 KiB，单回调峰值1–2ms。不同语言文字与索引不同，不能相加；无持续增长，热路径不枚举收藏，接受有界新功能目录成本。该数字不含实际游戏引擎对象，也不代表实机内存。

完整 tests/check_contract.ps1 通过（含4语言玩具回归、全部既有业务/性能门禁）；生成器、SDK、文档、190文件发布清单、Lua语法、Bindings.xml和git diff --check通过。Mainline/Mists/Wrath/TBC wowdoc validate通过；玩具数据与Provider只加载到Mainline。既有全量加载回归保持2个Frame/4个事件，新增目录Frame仅启用后创建。
