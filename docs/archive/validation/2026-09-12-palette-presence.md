# 主面板开关动效

## 目标与成本

用户要求修订 DESIGN.md，并让 Alt+Space 打开及 Esc 关闭面板具有连续、清晰可感知的动效。保持获批的布局、输入与安全动作规则，沿用原生 Alpha 动画，不引入整窗缩放、位移或模糊。

- 原实现：160 ms 从 0.72 淡入；失焦 Esc 的 CloseSpecialWindows 直接隐藏主框，绕过退场；退场重开先完成隐藏，再重新淡入。
- 目标：打开 220 ms 从 0 到 1，OUT；关闭 140 ms 从当前透明度到 0，IN。重开从当前显示值继续并按剩余透明度缩短入场，重复关闭不重播。
- 触发只来自开关动作；首次打开增加一个无图形、无输入脚本的 Esc 子框，后续复用。原生动画组复用且总上限仍为 96，不增加计时器或常驻 OnUpdate。
- 验收预算：首次打开额外 Frame ≤ 1；暖开关动画组增长 0；1,000 轮反向与完整开关的离线动画边界累计分配 < 512 KiB；结束后没有活动动画或完成回调。保持现有整体交互和安全回归预算。

## 实现与中断

1. 主框不再直接注册 UISpecialFrames；一个无图形子框接收原生同步 Hide，再进入与输入框 Esc 相同的 Palette:Hide。原生函数与全局键盘分发不改动。
2. 关闭立即停止搜索会话、释放安全按钮、清除焦点并禁用输入，视觉退场完成后清理页面和隐藏主框。快速重开先读取原生 GetSmoothProgress 对应的当前透明度，取消旧完成回调，再建立新会话。
3. 减少动态效果立即完成过渡；如果正在关闭，同时执行退出收尾，避免透明但未隐藏的主框。
4. 安全战斗状态脚本通过框体引用同时隐藏 Esc 子框和主框；非安全回调只停止工作，不在战斗中修改受保护几何。脱战保持关闭，下一次打开恢复接收框。
5. 外部强制隐藏立即取消动画。输入焦点继续沿用下一帧获取，避免 Alt+Space 的空格进入查询；不等待入场完成。
