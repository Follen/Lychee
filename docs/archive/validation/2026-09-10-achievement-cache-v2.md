# 成就缓存进一步优化：实施前预算

前版本 1d93d78。保留正确性与现有 1 ms 工作预算，不承诺理论最优。

目标：4 个角色 LRU，所有角色合计最多 32768 个条目、4 MiB 名称；超过时淘汰最久未用的非当前角色。相同 build/product/locale 下切回保留角色不读全目录，版本变化丢弃旧域。每份缓存保存 ID、文本、所属分类的平行数组和分类计数，不重复保存活动缓存副本。

分类变化：只枚举变化、新增的分类；移除分类剔除其旧条目；未变分类复用字符串和 ID，无 GetAchievementInfo 调用。为保证可取消与一致性，合并元数据为 O(N) 分批工作，完成后原子交换；不宣称整个更新为 O(变化条数)。完整构建使用分类枚举返回的名称，不再针对同 ID 二次读取；系列仍单独补齐。

预算：原有 6002 条单角色 <4 MiB、热10次分配 <4 MiB/保留增长 <64 KiB 不变；四角色数据累计仍受总容量约束。4→5 个角色必须淘汰且不影响当前查询。固定两个分类场景，只改变一个分类时，未变分类原生目录读取必须为 0；去重与最终集合与全扫描参考一致。旧版格式升级需重建一次，不伪装为已复用。7 天完整校验继续作为发现同数量内容替换的保守兜底，游戏实测后再调整周期。
