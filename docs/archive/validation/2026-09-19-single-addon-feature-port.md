## 本轮修复

- 设置页迁入后缺少来源分组、图标、说明与排序字段，管理层恢复旧内置显示元数据，第三方继续使用自己的声明。
- 来源同步就绪不再递归触发新查询使外层结果失效；异步就绪只合并必要刷新。
- 加载／准备被拒绝时结束等待并记录失败。同次输入保留其他来源尚未完成的准备，共享原始截止时间。
- 取消先撤下旧任务，回调重入不得清除新查询。
- Bootstrap 不因未知账号 schema 重置整份存档。该修复不等于多包存档转换已完成。
