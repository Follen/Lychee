# 主面板动效重做：实体化与阻尼停稳

用户实机反馈上一版纯淡入淡出观感不佳。本轮替代 2d9fafe 的整段透明度过渡，不以离线通过推断视觉质量。DESIGN.md 同步允许主面板开关的小幅真实缩放，其它控件动效不改。

## 设计、成本和边界

- 打开从 96% 到 100%，300 ms 临界阻尼停稳；透明度在归一化位置达到 0.30 后固定为 1，前段先建立实体感，避免长时间透出游戏背景。关闭用更强阻尼在 180 ms 内收拢到 96%，尾段消隐。
- 闭式临界阻尼解，打开角频率 30、关闭 40，终点准确复位；改变方向时继承当前位移和速度。归一化位置限制 0–1，不反复弹跳。低帧率不依赖固定积分步长。
- 真实 Frame:SetScale 同步绘制和实际点击区域；顶边锚点补偿缩放，搜索位置不向上下漂移，基准尺寸服从窗口适配比例。缩放、锚点和透明度只在值变化时更新，成功后写状态；回调重入有代次保护。
- 原生视觉 Scale 动画不能由离线证据证明与安全点击几何一致，且需要连续速度的反向控制，因此该主面板过渡使用一个独占短时驱动。最多一个活动任务和一个复用状态表，首次实际播放额外创建 1 个 Frame，开关结束解绑 OnUpdate 并隐藏，清除目标、布局与完成回调引用。模块加载和未打开时不创建驱动，不新增事件、timer 或常驻轮询。
- 预算：每帧无表/闭包/框体创建；1000 轮累计分配 <512 KiB；暖循环 Frame 与动画组增长为 0；零任务更新回调为 nil。单次开关最长 300/180 ms，首次输入不等待动画，安全动作仍按原规则执行。
- 关闭立即使输入、会话及安全动作失效；复用前一版的失焦 Esc 接收框与安全战斗隐藏。战斗开始/强制隐藏停止运动，不改受保护几何；脱战不自动打开。减少动态效果即时应用基准尺寸、锚点、透明度并执行必要关闭收尾。

## 验证

`tests/ui_motion.lua`：30/120 Hz 同一时刻的运动位置一致；反向位置和速度连续；顶边固定、基准缩放精确复位、减少动态效果、重复关闭、战斗抢占、setter 重入时旧完成回调不能关闭新状态均通过。

1000 轮序列包括半途开关反向，以及每轮按 120 Hz 步长完成 300 ms 打开与 180 ms 关闭。离线累计分配 179.69 KiB，本机本轮 CPU 总计 46 ms，新增 Frame/动画组 0；结束后驱动隐藏、OnUpdate=nil、活动引用清除。这个总耗时包括 Lua 替身和测试调用，不包含原生布局、字体重采样、实际绘制与安全点击，不用于宣称游戏帧率收益。

`tests/interaction_smoke.lua`：真实 Palette 生命周期下失焦 Esc 保留退场，结束隐藏；战斗脚本同时隐藏主框与 Esc 接收框，脱战重开恢复。已有安全动作、搜索、设置、Provider 与控件复用检查保留。

接口来源：wow-ui-source / retail / latest，resolvedCommit `8ea15b61e45c0ed4eba01439c90757f86eb78d34`，source check 无更新。Frame SetScale、SetPoint、SetScript 的精确证据见 [wowdoc 记录](2026-09-12-palette-spring-wowdoc.json)，不引用同名 ModelScene Actor 的 SetScale。

最终交付检查使用 `tests/check_contract.ps1`、wowdoc 77 Lua 校验及 git diff --check；日志 `%TEMP%/lychee-palette-spring-check.log`。未修改 TOC，同步后可 `/reload`。
