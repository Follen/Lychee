# 背包使用与定位

实现前预算：保持来源默认关闭；左键通过安全 item 动作使用，右键直接定位。定位点击最多扫描 1,024 格，定位原生合并/独立背包中的一个按钮。仅首次成功定位创建一个自有 Frame、五个 Texture，后续复用；原生背包按钮不改脚本、不改父节点。高亮 3 秒，最多一个 timer；关闭背包、背包内容变化、进入战斗、重复定位或停用取消效果与事件。无 OnUpdate、无后台重试，无全局 hook。

冷启动/稳态/峰值预算：新增高亮对象上限 1 Frame / 5 Texture；100 次定位累计分配低于 256 KiB，回收后保留增长低于 32 KiB；单次扫描上限 1,024 格，不随目录增长。安全物品动作复用已有行安全按钮池，不建立额外按钮池；不监听物品施放结果、不声称使用成功，使用规则与错误提示由原生 item 动作处理。受保护按钮属性仅脱战配置，身份失效后清空 item 属性。

缓存所有者为 Bags，高亮只保存当前自身框/当前格位锚点，隐藏后清除锚点与计时器。第三方完全替代背包没有通用按钮接口：保留打开/搜索，但无法取得可见原生按钮时明确反馈无法高亮，不偷偷高亮隐藏背包。

验证结果与 API 证据在交付前补齐；实机渲染、第三方背包及受保护动作均待游戏验证。没有新增登录/战斗/团本/姓名板常驻扫描，因此这些场景不以离线测试宣称通过。
