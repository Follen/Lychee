# SDK 示例

[简体中文](README.md) · [English](README.en.md)

| 示例 | 用途 |
| --- | --- |
| [ThirdPartyFixture](ThirdPartyFixture/ThirdPartyFixture.lua) | 普通条目、动作、拖动与页面；完整目录可作为独立插件安装。 |
| [ColdProvider](ColdProvider/README.md) | 完整原生 TOC 冷发现与独立 SV 示例。 |
| [ManagedProvider](ManagedProvider.lua) | 托管查询作用域，片段需接入自己的插件。 |
| [DeferredProvider](DeferredProvider.lua) | 延后注册示例，放入自己的加载生命周期。 |
| [ComponentPanel](ComponentPanel/ComponentPanel.lua) | 可复用 UI 页面插件，复制完整目录。 |

仅包含 TOC 的完整目录可作为示例插件安装，不安装 examples 总目录或整个 SDK。先核对客户端范围、阅读源码，再做实机验证；示例不代表全部客户端已验收。
