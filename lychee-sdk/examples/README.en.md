# SDK examples

[简体中文](README.md) · [English](README.en.md)

| Example | Purpose |
| --- | --- |
| [ThirdPartyFixture](ThirdPartyFixture/ThirdPartyFixture.lua) | Ordinary entries/actions/drag/views; copy its complete directory as an addon. |
| [ColdProvider](ColdProvider/README.en.md) | Complete native TOC discovery and addon-owned SV example. |
| [ManagedProvider](ManagedProvider.lua) | Managed query resources; integrate the snippet into your addon. |
| [DeferredProvider](DeferredProvider.lua) | Deferred registration example; integrate in your own load lifecycle. |
| [ComponentPanel](ComponentPanel/ComponentPanel.lua) | Reusable UI view addon; copy its complete directory. |

Only directories containing TOCs are installable examples. Do not install this examples folder or the whole SDK. Match your client scope, read the source and test in game. No example proves all-client compatibility.
